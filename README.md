# MydazTech

Site de ofertas e achadinhos de tecnologia.

## Estrutura inicial

- Busca de produtos
- Categorias
- Filtros por Shopee, Mercado Livre e Amazon
- Cards de ofertas
- Popup para grupo do WhatsApp
- Layout responsivo, pensado para celular
- Identidade preta e dourada
